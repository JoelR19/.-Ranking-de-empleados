# Practica-js scrum

## Ranking de empleados

En este proyecto realizare un filtrador de datos para saber cual es el ranking de empleados

### Se nos pide los siguientes requisitos:

- Calcular el total de ventas por empleado, ordenar y devolver
- Los dos mejores vendedores por sede
- Buscar vendedor
- Agregar vendedor con su total de ventas
- Un html en el cual se visualizara al usuario.

### Las herramientas utilizadas son:

- Javascript
- HTML
- CSS

### El repositorio contendra los siguientes archivos en las ramas de la siguiente manera:

#### main:

- index.html
  - Contendra el index de la pagina
- style.css
  - Contendra los estulos de la pagina

#### development:

- script.js
  - Contendra la funcionalidad de la pagina
